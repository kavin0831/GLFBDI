Simplest setup — no Google Cloud Console, no consent screen, no redirect URIs, no test users. Uses IMAP + SMTP with a 16-character App Password.

  2. Generate an App Password at myaccount.google.com/apppasswords (name it anything, e.g. "GLFBDI")
  3. Google shows a 16-character password like abcd efgh ijkl mnop — copy it
